*Рассмотрим следующую программу на С++.*
```
#include <iostream>
```

* ```const auto Pi = acos(0) * 2;```

* ```const auto Pi = acos(x) * 2;```

В первом варианте используется const. Значение Pi нельзя изменить после инициализации, но const само по себе не гарантирует вычисления значения на этапе трансляции.

Во втором варианте используется constexpr, поэтому выражение должно допускать вычисление во время компиляции. Возможность использования std::acos(0) зависит от версии стандарта C++ и реализации компилятора. Некоторые компиляторы вычисляют это выражение на этапе компиляции, тогда как другие могут сообщить об ошибке. В C++26 математическая функция std::acos стала constexpr.

В третьем варианте значение вычисляется через переменную x. Объявление с const допустимо, однако вычисление не обязано происходить на этапе трансляции.

Четвёртый вариант использует constexpr и переменную x, которая не является константой времени компиляции. Поэтому такое объявление не соответствует требованиям constexpr и приводит к ошибке компиляции.

Вывод: const запрещает обычное изменение значения после инициализации, а constexpr требует постоянного выражения. Для гарантированного объявления константы этапа трансляции можно написать constexpr double Pi = 3.141592653589793;.

### Задание 3 **(2)**
*Проверьте работу следующего фрагмента программы на С++.*
```
int s = 0;
for (int i = 0; i < 4; i++) {
   for (int i = 0; i < 3; i++) {
      s += i;
   } 
   s += i; 
}
std::cout << s;
```
*В результате каких вычислений был получен ответ? Дайте подробный ответ.*

В программе используются две разные переменные i, объявленные в заголовках циклов. Переменная внутреннего цикла временно скрывает внешнюю переменную с таким же именем.

Внутренний цикл выполняется три раза с i = 0, 1, 2, поэтому на каждой итерации внешнего цикла к сумме прибавляется 0 + 1 + 2 = 3. Внешний цикл выполняется четыре раза с i = 0, 1, 2, 3. После завершения внутреннего цикла к сумме дополнительно прибавляется значение внешней переменной i.

Таким образом, итоговая сумма равна 3 × 4 + (0 + 1 + 2 + 3) = 18.

Результат программы:

18

Вывод: в C++ внутренний и внешний циклы имеют разные переменные i. Внутренний цикл каждый раз прибавляет к сумме 3, а внешний дополнительно прибавляет числа от 0 до 3. Поэтому программа выводит 18.

За каждую итерацию внешнего цикла сумма увеличивается на 5. Поскольку внешний цикл выполняется четыре раза, итог равен 5 × 4 = 20.

### Задание 6 **(2)**

*Рассмотрим следующий фрагмент программы. Эта программа 1000000 раз обменивает значения двух длинных 
строк с использованием третьей строки. Проверьте, насколько быстро она работает.*

```
std::string a(100000, 'a');
std::string b(100000, 'b');
for (int i=0;i<1000000;i++) {
   std::string c(a);
   a = b;
   b = c;
}
std::cout << a[0] << b[0];
```
*Попробуйте использовать для обмена значений строк функцию* **swap**. 
*Проверьте, изменилось ли время работы. В чем ошибка исходной программы?
Исправьте исходную программу, чтобы ускорить ее работу. Изменения не должны 
затрагивать общий вид программы (присваивания, использование временной переменной).*

В исходном варианте строки обмениваются значениями с помощью временной переменной c. При этом создаются копии строк длиной 100000 символов. Поскольку обмен выполняется миллион раз, копирование требует значительного времени.

Первый способ ускорения — использование swap:

std::string a(100000, 'a');
std::string b(100000, 'b');

for (int i = 0; i < 1000000; i++) {
    a.swap(b);
}

std::cout << a[0] << b[0];

Функция swap обменивает внутренние данные строк без копирования всех их символов, поэтому работает значительно быстрее.

Второй способ — сохранить первоначальную структуру программы, но использовать перемещение:

std::string a(100000, 'a');
std::string b(100000, 'b');

for (int i = 0; i < 1000000; i++) {
    std::string c(std::move(a));
    a = std::move(b);
    b = std::move(c);
}

std::cout << a[0] << b[0];

Функция std::move позволяет использовать семантику перемещения. Вместо создания полных копий строк передаются их внутренние ресурсы. Это уменьшает затраты времени на обмен.

После миллиона обменов во всех вариантах выводятся символы:

ab

Поскольку количество обменов чётное, строки возвращаются к первоначальным значениям.

Вывод: недостаток исходной программы заключается в многократном копировании больших строк. Использование swap или семантики перемещения позволяет значительно ускорить выполнение программы. Точные времена работы необходимо определить экспериментально для каждого варианта.

Команда b = a не создаёт копию строки. Теперь обе переменные ссылаются на один объект, поэтому id(a) и id(b) совпадают.

a = Hello world and goodbye
b = Hello world

Вывод: переменные Python хранят ссылки на объекты. Присваивание одной переменной другой копирует ссылку, а изменение содержимого неизменяемой строки приводит к получению нового строкового объекта.

###  Задание 9 **(3)**
*Напишите программу на языке* **Python**, *которая создаст 2600 переменных с именами
от* **a0** *до* **a99**, *от* **b0** *до* **b99** *и так далее, от* **z0** *до* **z99**. 
*Присвойте всем переменным различные значения от 1 до 2600.*


n = 1

for letter in 'abcdefghijklmnopqrstuvwxyz':
    for i in range(100):
        globals()[letter + str(i)] = n
        n += 1

print(a0, a99)
print(b0, b99)
print(z0, z99)

Результат программы:

1 100
101 200
2501 2600

Внешний цикл последовательно перебирает 26 латинских букв от a до z. Внутренний цикл перебирает числа от 0 до 99.

На каждой итерации выражение letter + str(i) формирует имя новой переменной, например a0, a1, b0 или z99.

Функция globals() возвращает словарь глобального пространства имён. Добавление записи в этот словарь позволяет динамически создавать переменные с нужными именами.

Переменная n содержит очередное значение. После создания каждой переменной она увеличивается на единицу, поэтому все значения различны.

Общее количество созданных переменных: 26 × 100 = 2600.

Вывод: в Python переменные можно создавать динамически через словарь пространства имён. Каждому сформированному имени соответствует отдельная запись, содержащая ссылку на присвоенное значение.

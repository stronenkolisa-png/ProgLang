```
#include <iostream>
int main() {
   {

      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   return 0;
}
```
*Нужны ли в этой программе вложенные фигурные скобки? Дайте подробный ответ с объяснением причин.*

Вложенные фигурные скобки необходимы для разделения областей видимости. В первом блоке объявляются переменные x и y типа int, а во втором переменные с такими же именами, но типа double. Если убрать вложенные скобки, возникнет ошибка компиляции из-за повторного объявления переменных в одной области видимости.

Таким образом, фигурные скобки позволяют использовать одинаковые имена для переменных разных типов в одной функции.

В исходном варианте строки обмениваются значениями с помощью временной переменной c. При этом создаются копии строк длиной 100000 символов. Поскольку обмен выполняется миллион раз, копирование требует значительного времени.

Использование swap:

int main() {
    std::string a(100000, 'a');
    std::string b(100000, 'b');

    for (int i = 0; i < 1000000; i++) {
        a.swap(b);
    }

    std::cout << a[0] << b[0];
}

<img width="574" height="366" alt="image" src="https://github.com/user-attachments/assets/829d5303-fe98-46e4-875e-87b1c1743db5" />

Функция swap обменивает внутренние данные строк без копирования всех их символов, поэтому работает значительно быстрее.

Сохранить первоначальную структуру программы, но использовать перемещение:

int main() {
    std::string a(100000, 'a');
    std::string b(100000, 'b');

    for (int i = 0; i < 1000000; i++) {
        std::string c(std::move(a));
        a = std::move(b);
        b = std::move(c);
    }

    std::cout << a[0] << b[0];
}

<img width="598" height="422" alt="image" src="https://github.com/user-attachments/assets/f798ef8b-515f-4597-8f8a-86c92bab16c1" />

Функция std::move позволяет использовать семантику перемещения. Вместо создания полных копий строк передаются их внутренние ресурсы. Это уменьшает затраты времени на обмен.

После миллиона обменов во всех вариантах выводятся символы `ab`

Поскольку количество обменов чётное, строки возвращаются к первоначальным значениям.

Причина медленной работы исходной программы заключается в многократном копировании содержимого строк. Функция swap позволяет обменивать внутренние данные строк без копирования всех символов. При использовании std::move применяется семантика перемещения, которая позволяет передавать ресурсы строки вместо создания её полной копии.
Использование swap и std::move значительно ускоряет обмен длинных строк. В проведённом эксперименте самым быстрым оказался вариант с swap. При этом std::move позволяет сохранить исходную структуру программы с временной переменной и присваиваниями.

###  Задание 9 **(3)**
*Напишите программу на языке* **Python**, *которая создаст 2600 переменных с именами
от* **a0** *до* **a99**, *от* **b0** *до* **b99** *и так далее, от* **z0** *до* **z99**. 
*Присвойте всем переменным различные значения от 1 до 2600.*

n = 1

for letter in 'abcdefghijklmnopqrstuvwxyz':
    for i in range(100):
        globals()[letter + str(i)] = n
        n += 1

print(a0, a99)
print(b0, b99)
print(z0, z99)

<img width="537" height="268" alt="image" src="https://github.com/user-attachments/assets/e0c413e5-01b8-44c4-ad08-1d5f9e48b5e7" />

При выполнении программы были созданы 2600 переменных с именами от a0 до z99, которым присвоены различные значения от 1 до 2600.

Внешний цикл перебирает 26 букв латинского алфавита, а внутренний числа от 0 до 99. Из буквы и числа формируется имя переменной. С помощью функции globals() это имя добавляется в словарь глобальных переменных, а значение n увеличивается на единицу.

Для проверки были выведены значения нескольких переменных: a0 = 1, a99 = 100, b0 = 101, b99 = 200, z0 = 2501 и z99 = 2600.

В Python можно динамически создавать переменные через словарь глобального пространства имён. Функция globals() позволяет обращаться к этому словарю и добавлять в него новые имена. Программа успешно создала все 2600 переменных с различными значениями.

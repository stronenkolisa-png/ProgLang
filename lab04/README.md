### Задание 5. **(2)**

*Объясните работу фрагмента программы на С++. В частности, почему* $x+x-x=x$, *но при этом*
$(x\cdot 2)/2\neq x$? *В отчете надо привести вычисления, приводящие к ответу.*
```
unsigned short x = 40000;
unsigned short y = x + x;
unsigned short z = x * 2;
y = y - x;
z = z / 2;
std::cout << y << " " << z << std::endl;
```
`unsigned short` содержит 16 бит

При вычислении

```
x + x = 40000 + 40000 = 80000
```

происходит переполнение. По модулю `2^16 = 65536` получаем:

```
80000 - 65536 = 14464
```

Поэтому после выражений

```
unsigned short y = x + x;
unsigned short z = x * 2;
```

обе переменные имеют значение 14464.

Далее выполняется:

```
y = 14464 - 40000 = -25536
```

Для беззнакового 16-битного числа это значение соответствует:

```
-25536 + 65536 = 40000
```

Поэтому `y` снова становится равным 40000.

Для переменной `z` выполняется обычное деление уже переполненного значения:

```
z = 14464 / 2 = 7232
```

Итог программы:

```
40000 7232
```

Таким образом, выражение `x + x - x` снова приводит к исходному значению, так как арифметика выполняется по модулю `2^16`. В выражении `(x * 2) / 2` после умножения исходное значение 80000 уже было заменено на 14464, поэтому деление выполняется не над 80000, а над 14464

В отчете надо привести вычисления, приводящие к ответу.*
```
std::cout << 2000000000 + 1000000000 << std::endl;
std::cout << 2000000000U + 1000000000U << std::endl;
std::cout << 2500000000U + 2500000000U << std::endl;
std::cout << 2500000000LL + 2500000000LL << std::endl;

```
Для 32-битного целого числа значение `2^32` равно:

```
4294967296
```

В первом выражении:

```
2000000000 + 1000000000
```

получается 3000000000. Это значение выходит за диапазон знакового 32-битного типа

```
3000000000 - 4294967296 = -1294967296
```

Во втором выражении литералы имеют суффикс `U`, вычисление производится для беззнакового типа:

```
2000000000 + 1000000000 = 3000000000
```

Значение помещается в диапазон `unsigned int`, результат равен 3000000000

Для следующего выражения:

```
2500000000 + 2500000000 = 5000000000
```

происходит переполнение беззнакового 32-битного типа:

```
5000000000 - 4294967296 = 705032704
```

Литералы с суффиксом `LL` имеют тип `long long`, поэтому число 5000000000 помещается в тип без переполнения

Умножение

```
20000 * 200000 = 4000000000
```

также помещается в `unsigned int`.

Последнее произведение равно:

```
200000 * 200000 = 40000000000
```

Остаток по модулю `2^32`:

```
4294967296 * 9 = 38654705664
40000000000 - 38654705664 = 1345294336
```

Ожидаемый вывод программы:

```
-1294967296
3000000000
705032704
5000000000
4000000000
1345294336
```

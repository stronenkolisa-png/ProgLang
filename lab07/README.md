правильной? Будет ли она обменивать значения переменных? Как в языке С++ вычисляется это выражение?*

Программа скомпилировалась, но значения переменных не изменились: a = 3, b = 7. Это происходит потому, что присваивание = имеет более высокий приоритет, чем оператор запятой. Поэтому строка a, b = b, a; выполняется как a, (b = b), a;

### Задание 7 **(2)**

*Как работает следующая программа? Как зависит результат от исходного значения?*
```
int x;
std::cin >> x;
x-->0 && x-->0 && x-->0 && x-->0 && x-->0;
std::cout << x;
```



Запись x-->0 состоит из токенов x, --, > и 0. Отдельного оператора --> нет. Постфиксный декремент -- имеет более высокий приоритет, чем сравнение >, а сравнение более высокий, чем &&. Поэтому выражение понимается так:
```
((x--) > 0) && ((x--) > 0) && ((x--) > 0) && ((x--) > 0) && ((x--) > 0);
```
Оператор x-- возвращает прежнее значение x для сравнения и уменьшает саму переменную на единицу. Это уменьшение является побочным действием. Оператор && выполняет проверки слева направо, причём уменьшение x завершается до следующей проверки. Если очередное сравнение ложно, оставшаяся часть выражения не вычисляется

При вводе 1000 сравниваются значения 1000, 999, 998, 997 и 996. Все они больше нуля, поэтому выполняются все пять декрементов и выводится 995

Если введено число от 1 до 4, результат равен -1: значение уменьшается до нуля, затем проверка 0 > 0 даёт ложь, но декремент в ней всё равно уменьшает x до -1. <img width="589" height="287" alt="image" src="https://github.com/user-attachments/assets/ee1ad27a-c557-4e56-bdee-7f4a0e7aeb6e" />

Выражение (s += i) += j прибавляет к переменной s сначала i, затем j. Выражение (i < j ? i : j)++ увеличивает i, если i < j, иначе увеличивает j. При равенстве увеличивается j.

В начале i = 0, j = 5, s = 0. Последовательно вычисляем сумму на каждом проходе:
```
i = 0, j = 5: s = 0 + 0 + 5 = 5
i = 1, j = 5: s = 5 + 1 + 5 = 11
i = 2, j = 5: s = 11 + 2 + 5 = 18
i = 3, j = 5: s = 18 + 3 + 5 = 26
i = 4, j = 5: s = 26 + 4 + 5 = 35
i = 5, j = 5: s = 35 + 5 + 5 = 45
i = 5, j = 6: s = 45 + 5 + 6 = 56
i = 6, j = 6: s = 56 + 6 + 6 = 68
i = 6, j = 7: s = 68 + 6 + 7 = 81
i = 7, j = 7: s = 81 + 7 + 7 = 95
i = 7, j = 8: s = 95 + 7 + 8 = 110
i = 8, j = 8: s = 110 + 8 + 8 = 126
```
После последнего прохода j увеличивается до 9. Условие i + j <= 16 становится ложным, поскольку 8 + 9 = 17. Цикл завершается. По ручному расчёту программа должна вывести 126, что совпадает с результатом запуска

## Практикум 3
### 1 задача
```
n = int(input())
c = (n + 24) // 25
s = n // c
print(c, s)
```
Для нахождения количества классов - делим n на 25 с округлением вверх. Для размера самого маленького класса нужно поделить количество учеников поровну, отбрасывая остаток. 

### 2 задача
```
t = int(input())

while t > 0:
    n = int(input())
    p, q = map(int, input().split())
    
    res = '0.'  

    while n > 0:
        p = p * 2                         #удваиваем числитель
        res = res + str(p // q)           #добавляем цифру 0 или 1 к ответу и сохраняем остаток
        p = p % q
        n = n - 1                         #когда находим одну цифру чтобы перейти к следующей -1
    print(res)
    t = t - 1                             #уменьшаем количество наборов
```

### 3 задача
```
t = int(input())
cnt = 0 
while cnt < t:
    a, b, c, d, e, f, g, h = map(int, input().split())

    left = (a * d + c * b) * f * h              #складываем дроби приводя к общему знам
    right = (e * h + g * f) * b * d             #сравниваем дроби перемножая крест накрест

    cnt = cnt + 1

    if left < right:
        print(-1, end=' ')                      #если левая дробь меньше правой -1
    elif left > right:
        print(1, end=' ')                       #иначе если левая больше правой 1
    else:
        print(0, end=' ')                       #иначе если значения равны
```

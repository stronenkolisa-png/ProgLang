### Задание 1 **(3)**

* **Тип в программировании** - атрибут объекта данных, задающий множество допустимых значений и методы для работы с ними
* **Статическая типизация** - язык программирования обладает статической типизацией, если тип объекта данных определяется в момент трансляции
* **Динамическая типизация** - язык программирования обладает динамической типизацией, если тип объекта данных определяется на этапе выполнения программы в момент создания или присваивания значения
* **Неявная типизация** - тип определяется на этапе трансляции автоматически по тексту программы
* **Явное преобразование типа** - преобразование типа называется явным, если оно указано в программе в виде вызова функции или в виде операции
* **Неявное преобразование типа** - преобразование типа называется неявным, если оно не присутствует в программе в виде конкретного указания, однако транслятор сам подставляет требуемый метод преобразования
* **Сильная типизация** - язык программирования не содержит или почти не содержит правил неявного преобразования типа
* **Слабая типизация** - язык программирования содержит большое число правил неявного преобразования типа и допускает каламбуры типизации

*Преобразования при арифметических действиях*
1. Если длины обоих типов меньше int, происходит преобразование к int.
2. Если типы разной длины, меньший преобразуется к большему.
3. Если типы одинаковой длины и один тип знаковый, а другой беззнаковый, знаковый приводится к беззнаковому.
4. Если один операнд целый, а другой вещественный, целый приводится к вещественному.
```
//Пример:

double y = 2.0;

x преобразуется в double, поэтому результат:
2.5

```

### Задание 6 **(2)**

Рассмотрим следующий фрагмент программы. 
```
int a = -1, b = 1;
unsigned int c = 1;
std::cout << a*b << std::endl;
std::cout << a*c << std::endl;
```
#### Пояснение

В выражении `a * b` обе переменные имеют тип `int`, поэтому никакого преобразования типов не происходит. Значения равны `-1` и `1`, поэтому результатом будет `-1`.

В выражении `a * c` переменная `a` имеет тип `int`, а переменная `c` - `unsigned int`. Эти типы имеют одинаковую длину, но `int` является знаковым типом, а `unsigned int` - беззнаковым. По правилам неявного преобразования типов в C++ знаковое значение в такой ситуации приводится к беззнаковому типу. Поэтому значение `-1` преобразуется в большое положительное беззнаковое число. При обычном 32-битном `unsigned int` это значение равно `4294967295`. Поэтому первая строка программы выводит `-1`, а вторая - `4294967295`.

Если заменить `int` на `short`, а `unsigned int` на `unsigned short`, ситуация изменится. Типы `short` и `unsigned short` имеют длину меньше `int`, поэтому перед выполнением арифметической операции они приводятся к типу `int`. В результате и в выражении `a * b`, и в выражении `a * c` вычисление происходит уже с целыми знаковыми значениями. Поэтому в обоих случаях результат будет равен `-1`.

### Задание 7 **(2)**
Рассмотрим следующий фрагмент программы.
```
int x = 7, y = 4;
long double d = 0.25;
cout << (x / y) / d << endl;
cout << (x / d) / y << endl;
long a = 200000, b = 200000;
long long c = 200000;
std::cout << (a * b) * c << std::endl;
std::cout << a * (b * c) << std::endl;
```
#### Пояснение

В первом выражении `(x / y) / d` сначала выполняется деление `x / y`. Переменные `x` и `y` имеют тип `int`, поэтому выполняется целочисленное деление: `7 / 4 = 1`. После этого результат `1` делится на `d = 0.25`. Так как один операнд целый, а другой вещественный, целое значение приводится к вещественному. В результате получаем `1 / 0.25 = 4`.

Во втором выражении `(x / d) / y` сначала выполняется деление `7 / 0.25`. Переменная `x` имеет тип `int`, а `d` - `long double`, поэтому целое значение `x` приводится к вещественному типу. Получаем `28`, после чего выполняется `28 / 4 = 7`. Таким образом, результаты отличаются: первое выражение дает `4`, а второе - `7`. Причина в том, что в первом случае сначала выполняется целочисленное деление и дробная часть теряется, а во втором преобразование к вещественному типу происходит раньше.

В выражении `(a * b) * c` сначала перемножаются `a` и `b`. Обе переменные имеют тип `long`, поэтому промежуточный результат также вычисляется в типе `long`. Только после этого он участвует в операции с переменной `c` типа `long long`. Если промежуточный результат не помещается в тип `long`, переполнение происходит еще до преобразования к `long long`.

В выражении `a * (b * c)` сначала вычисляется `b * c`. Переменные имеют типы `long` и `long long`, поэтому по правилам неявного преобразования меньший тип приводится к большему, и вычисление выполняется в типе `long long`. После этого `a` также участвует в операции с результатом типа `long long`. Поэтому изменение порядка действий меняет момент, когда происходит преобразование к более длинному типу, и из-за этого результат вычисления может отличаться.

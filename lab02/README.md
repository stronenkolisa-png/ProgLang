Строка объявления переменной по очереди заменяется на каждую из следующих строк. Каждая проверка запускается отдельно:

### Задание 2 **(2)**

**Программа на C++**

```
int main() {
    int a = 1, b = 2;
    int c = a++b;
    return 0;
}
```

При компиляции возникает ошибка. Сообщение g++:

```
error: expected ‘,’ or ‘;’ before ‘b’
```

Последовательность токенов C++ — токены разделены пробелами:

```
int main ( ) {
    int a = 1 , b = 2 ;
    int c = a ++ b ;
    return 0 ;
}
```

В C++ существует оператор `++`. Поэтому запись `a++b` разбивается на три токена:

```
a ++ b
```

После выражения `a++` без оператора записана переменная `b`. Такая запись содержит синтаксическую ошибку.

**Программа на Python**

```
a = 1
b = 2
c = a++b
```

Последовательность токенов без служебных токенов конца строки и файла:

```
a = 1
b = 2
c = a + + b
```

В Python оператора `++` нет. Поэтому выражение воспринимается так:

```
c = a + (+b)
```

Первый плюс означает сложение, второй — унарный плюс. Унарный плюс не меняет значение данного числа.

Для проверки значений добавлен вывод:

```
a = 1
b = 2
c = a++b
print(a, b, c)
```

Результат:

```
1 2 3
```

**Вывод:** программа Python выполняется без ошибок. Исходная программа без `print` ничего не выводит.

### Задание 3 **(2)**

Для проверки значений переменных добавлен вывод:

```
#include <iostream>
using namespace std;

int main() {
    int a = 1, b = 2;
    int c = a+++b;
    cout << a << " " << b << " " << c;
    return 0;
}
```

Программа компилируется и выполняется без ошибок.

Результат:

```
2 2 3
```

Последовательность токенов исходной программы из условия, без добавленного вывода:

```
int main ( ) {
    int a = 1 , b = 2 ;
    int c = a ++ + b ;
    return 0 ;
}
```

Запись `a+++b` воспринимается как:

```
a++ + b
```

Постфиксный оператор `a++` даёт для сложения прежнее значение `a`, равное `1`, и увеличивает саму переменную на единицу.

После выполнения:

```
a = 2
b = 2
c = 3
```

**Изменение разбиения на токены**

Пробелами можно изменить разбиение. Заменяем строку вычисления:

```
int c = a+ ++b;
```

Токены выражения:

```
a + ++ b
```

Префиксный оператор `++b` увеличивает `b` и даёт для сложения новое значение, равное `3`.

Результат:

```
1 3 4
```

Также можно разделить все три плюса:

```
int c = a + + + b;
```

Токены выражения:

```
a + + + b
```

Это сложение `a` и `+(+b)`. Значения `a` и `b` не изменяются.

Результат:

```
1 2 3
```

Каждый вариант проверяется отдельно с начальными значениями `a = 1`, `b = 2`.

### Задание 4 **(2)**

Круглые скобки являются оператором вызова функции:

```
print(5)
```

Здесь вызывается функция `print`, которой передаётся число `5`.

Круглые скобки не являются оператором, когда задают порядок вычислений:

```
a = (2 + 3) * 4
```

Сначала выполняется сложение, затем умножение. Получается `a = 20`.

Также круглые скобки не являются оператором в условии `if` на C++:

```
if (a > 0) {
    a = a - 1;
}
```

Здесь скобки выделяют условие.

Квадратные скобки являются оператором индексирования — обращения к элементу по его индексу:

```
a = [10, 20, 30]
print(a[1])
```

В выражении `a[1]` выбирается элемент с индексом `1`. Нумерация начинается с нуля, поэтому выводится `20`.

В записи `[10, 20, 30]` квадратные скобки используются для создания списка, а не для обращения к элементу.

### Задание 5 **(3)**

```
print(*map(sum, zip(
    *[map(int, input().split()) for i in (1, 2, 3)]
)))
```

Программа читает три строки целых чисел и выводит суммы чисел по столбцам.

**Ключевые слова:** `for`, `in`.

**Идентификаторы:** `print`, `map`, `sum`, `zip`, `int`, `input`, `split`, `i`.

**Литералы:** `1`, `2`, `3`.

**Назначение идентификаторов:**

 `i` - переменная перебора.
 `print`, `sum`, `input` - имена встроенных функций.
 `split` - имя метода строки.
 `int`, `map`, `zip` - имена встроенных типов, которые в программе вызываются как функции.

**Операции и обозначения:**

 `()` после имени функции или метода - вызов.
 `*` - распаковка элементов в отдельные аргументы, а не умножение.
 `.` - обращение к методу в записи `input().split()`.

Квадратные скобки ограничивают списковое включение. Круглые скобки в `(1, 2, 3)` оформляют кортеж и не обозначают вызов функции.

**Вызовы, их аргументы и результаты:**
`input()` - вызывается без аргументов. Возвращает введённую строку.
`.split()` - вызывается без явных аргументов. Разбивает строку по пробельным символам и возвращает список строк.
`map(int, ...)` - принимает `int` и список строк. Возвращает итератор, при переборе которого строки преобразуются в целые числа.
`int(...)` - принимает строку с числом и возвращает целое число.
`zip(...)` - принимает три распакованных итератора. Возвращает итератор кортежей, объединяющих числа одинаковой позиции.
`map(sum, ...)` - принимает `sum` и результат `zip`. Возвращает итератор сумм.
`sum(...)` - принимает кортеж чисел и возвращает их сумму.
`print(...)` - принимает распакованные суммы и выводит их через пробел. Возвращает `None`.

`int` и `sum` вызываются при переборе соответствующих объектов `map`.
**Пример входных данных:**

```
1 2 3
4 5 6
7 8 9
```

**Порядок работы:**

1. Перебор `i` по кортежу `(1, 2, 3)` задаёт три повторения. Само значение `i` в вычислениях не используется.
2. `input()` читает строку, а `split()` разбивает её на отдельные записи чисел.
3. `map(int, ...)` подготавливает преобразование записей в целые числа.
4. Звёздочка перед списком передаёт три итератора отдельными аргументами `zip`.
5. `zip` объединяет числа по столбцам: `(1, 4, 7)`, `(2, 5, 8)`, `(3, 6, 9)`.
6. `map(sum, ...)` вычисляет суммы: `12`, `15`, `18`.
7. Звёздочка перед внешним `map` передаёт суммы отдельными аргументами `print`.

**Вывод:**

```
12 15 18
```

Если строки содержат разное количество чисел, `zip` останавливается на самой короткой последовательности.

### Задание 6 **(2)**

В C++ есть однострочные и многострочные комментарии.

Однострочный комментарий:

```
// Комментарий до конца строки
```

Многострочный комментарий:

```
/* Комментарий
   на нескольких строках */
```

**Пример 1**

```
cout << "Hello /* Это комментарий */ world";
```

Верно. Обозначения комментария находятся внутри строкового литерала и являются обычным текстом.

Вывод:

```
Hello /* Это комментарий */ world
```

**Пример 2**

```
// /*
 Это комментарий
*/
```

Неверно. `//` комментирует только первую строку. На ней `/*` не открывает многострочный комментарий. Следующие строки остаются частью кода и вызывают ошибки.

**Пример 3**

```
/* Я комментирую программы /* комментарий */ */
```

Неверно. Многострочные комментарии в C++ не вкладываются друг в друга. Первый `*/` закрывает комментарий, а последний `*/` остаётся в коде и вызывает ошибку.

**Пример 4**

```
// Я комментирую программы /* комментарий */
```

Верно. Вся строка после `//` является комментарием и не влияет на выполнение программы.

**Пример 5**

```
/* Я комментирую свои программы
// Это комментарий до конца строки */
*/
```

Неверно. Комментарий начинается с первого `/*` и заканчивается на `*/` во второй строке. Находящийся внутри него знак `//` этого не меняет. Последний `*/` остаётся в коде и вызывает ошибку.

**Вывод:** верны примеры 1 и 4, неверны примеры 2, 3 и 5.

### Задание 7 **(4)**

Как видно из правил, есть **4 формы инструкции цикла**.

Первый вид цикл **while**, который соответствует строке правила:

```
while ( condition ) statement
```

Формат записи (по правилу): ключевое слово **«while»**, в круглых скобках условие **«condition»**, далее инструкция **«statement»**.

Пример фрагмента программы:

```
int x = 1;
while (x < 4) {
    cout << x << " ";
    x++;
}
```

Второй вид цикл **do…while**, который соответствует строке правила:

```
do statement while ( expression ) ;
```

Формат записи (по правилу): ключевое слово **«do»**, далее инструкция **«statement»**, ключевое слово **«while»**, в круглых скобках выражение **«expression»**, далее точка с запятой.

Пример фрагмента программы:

```
int x = 1;
do {
    cout << x << " ";
    x++;
} while (x < 4);
```

Третий вид цикл **for**, который соответствует строке правила:

```
for ( init-statement condition_opt ; expression_opt ) statement
```

Формат записи (по правилу): ключевое слово **«for»**, в круглых скобках начальная инструкция **«init-statement»**, включающая точку с запятой, необязательное условие **«condition»**, точка с запятой, необязательное выражение **«expression»**, далее инструкция **«statement»**.

Обозначение **«opt»** означает необязательную часть. В этой записи `_opt` заменяет нижний индекс из документа.

Пример фрагмента программы:

```
for (int x = 1; x < 4; x++) {
    cout << x << " ";
}
```

Четвёртый вид цикл **for по диапазону**, который соответствует строке правила:

```
for ( for-range-declaration : for-range-initializer ) statement
```

Формат записи (по правилу): ключевое слово **«for»**, в круглых скобках объявление переменной **«for-range-declaration»**, двоеточие, диапазон **«for-range-initializer»**, далее инструкция **«statement»**.

Пример фрагмента программы:

```
int numbers[3] = {1, 2, 3};
for (int x : numbers) {
    cout << x << " ";
}
```
### Задание 8 **(3)**

Исходный фрагмент из условия:

```
int main() {
    int a, x, y, z;
    cin >> x >> y >> z;
    a = -x + y * (z - 1);
}
```

Абстрактное синтаксическое дерево для выражения:

```
a = -x + y * (z - 1);
```

Унарный минус применяется к `x`. Результат вычитания `z - 1` умножается на `y`. Затем складываются `-x` и результат умножения. Полученное значение присваивается переменной `a`.

Скобки отдельными узлами не показываются: порядок вычислений отражён связями дерева.
